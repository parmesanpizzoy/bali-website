DE'NIRA — Indonesia Travel Website

Based in Bali. Explore All of Indonesia.

DE'NIRA is a concept website for a Bali-based travel agency and tour operator, showcasing curated tours and tailor-made journeys across the Indonesian archipelago — from Bali and Java to Komodo, Flores, and Raja Ampat.

✨ Features
Cinematic full-screen hero section
Destination showcase grid (Bali, Java, Komodo & Flores, Lombok & Gili Islands, and more)
Featured tours & travel packages
Editorial-style journal / blog section
Fully responsive layout
Built with a modern React + Vite stack

React 19

📦 Getting Started
Prerequisites
Node.js (LTS version recommended)
npm (comes bundled with Node.js)
Installation
bash
# Clone the repository
git clone https://github.com/your-username/denira.git
cd denira

# Install dependencies
npm install

# Start the development server
npm run dev

The site will be available at http://localhost:5173.

Build for production
bash
npm run build

This generates a production-ready build inside the dist/ folder, which can be deployed to any static hosting provider (e.g. Vercel, Netlify, GitHub Pages).
